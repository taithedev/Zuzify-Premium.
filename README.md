# Zuzify Premium

A separate Zuzify product for premium access, customization, account settings, and premium-only controls.

This project is intentionally separate from Zuzify Socials.

## Included
- Supabase-ready authentication
- Premium subscription state
- Premium feature gating foundation
- Theme and customization controls
- Account settings
- Premium management foundation
- Responsive dark liquid-glass interface
- No AI features
- No badges

## Supabase
Configure the project URL and publishable key in `src/config.js`.

Production subscription changes should be authorized server-side and protected with RLS.
